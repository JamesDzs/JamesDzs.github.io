Agent-Zeshi

Privacy policy

Last updated 20 November 2026

Agent-Zeshi is a personal assistant used only by its owner. Only the owner's own Google account is connected to it.

What Google data it accesses

  • Google Calendar: events, to answer the owner's questions about their schedule. With the owner's approval of each one, it creates events to block time.
  • Gmail: read-only access to messages and settings, used only when the owner asks about their email.

How the data is used and stored

  • Data is used only to answer the owner's own requests and to show the owner their own information.
  • The sign-in token and any notes the assistant keeps are stored on the owner's private server.
  • To answer a request, the relevant content is sent to the AI model provider that powers the assistant, only to produce the answer.
  • Google user data is never sold, shared with anyone else, or used for advertising.

Google API Services User Data Policy

Agent-Zeshi's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. The stored sign-in token then stops working, and the owner deletes it from the server.
