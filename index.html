Agent-Zeshi

Agent-Zeshi is a personal assistant that runs on its owner's own server and is used only by its owner. It is not offered to anyone else.

What it does

  • Google Calendar: reads the owner's calendar so it can answer questions about their schedule. It can add an event to block time, but only after the owner approves that specific event.
  • Gmail: searches and reads the owner's email when they ask about it. It can save a reply as a draft, but only after the owner approves that exact draft. It cannot send, label or delete mail.
